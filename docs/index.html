請求書・注文書の読み取りと一覧化

書類から日付・取引先・品目・金額を読み取った結果を、人が確認・修正して、CSV に書き出すところまでの画面です。

このデモの読み取り結果は、同梱のプロンプト（prompts/extract_prompt.md）と同じ指示で事前に処理したものです。 この画面から API は呼びません。書類はすべて架空のサンプルです。

書き出し

各書類の数字が合っているかは、画面が自動で突き合わせます（明細の合計＝小計、小計＋消費税＝合計、数量×単価＝金額）。合わない書類は「要確認」のまま書き出されます。

CSV は UTF-8（BOM 付き）で、1明細＝1行です。小計・消費税・合計は書類の最初の行にだけ入ります。編集した内容はこのタブの中だけにあり、再読み込みで元に戻ります。

安全性の確かめ方（1分でできます）

「保存していません」と書くだけでは証明にならないので、ブラウザ自身が、このページから外への通信を禁止している状態にしています。次の3つを、ご自分で確かめてください。

  1. ページのソースを見る。 このページで右クリック →「ページのソースを表示」。<head> の先頭付近（文字コード指定の直後）に、下の Content-Security-Policy（ブラウザに「このページは外へデータを送ってはいけない」と守らせる設定）があります。CSP より前に外部の読み込みはありません。connect-src 'none' は、スクリプトからの通信（fetch・XHR・WebSocket など）を許可しない指定です。画像や外部ファイルの読み込みは、同じ設定内の他の項目で止めています。リンクのクリックによる移動は対象外です。
  2. 開発者ツールの Network タブを見る。 F12 → Network を開いてページを再読み込みすると、表示されるのはこのサイト自身のファイル（HTML・CSS・JS・画像）だけです。外部ドメインへの通信は 0 件です。
  3. キーの入力欄が無いことを見る。 このページの入力欄は、書類の項目（日付・取引先・金額など）と「自社名」だけです。API キーやパスワードを入れる欄は無く、API を呼ぶコードも含まれていません（app.js・lib.js は誰でも読める長さです）。外への通信を試みるのは、下の「わざと試す」ボタン（csp-probe.js）だけで、データは何も載せません。
